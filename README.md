# Поиск автозапчастей и аналогов

Двухэтапный подбор деталей через использование Web-сервиса «Проценка».

Стек: React, Redux Toolkit, Bootstrap.

## Функциональность

- Поиск производителей по артикулу детали.
- Выбор производителя из полученного списка.
- Поиск предложений и аналогов по артикулу и производителю.
- Отображение названия, производителя, цены и доступного остатка.
- Обработка загрузки, ошибок API и отсутствия результатов.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить приложение:

```bash
npm run dev
```

## API

Для получения данных используется API Web-сервиса «Проценка».

Документация: https://lk.favorit-parts.ru/static/wsprice.pdf

Поиск выполняется в два этапа: сначала по артикулу, затем по артикулу и выбранному производителю с запросом аналогов.

Доступность результатов зависит от ограничений внешнего API, включая лимит количества запросов.
